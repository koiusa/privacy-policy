# プライバシーポリシー

[koiusa]（以下、「当方」といいます。）は、スマートフォン用アプリケーション「MMD立体視」（以下、「本アプリ」といいます。）における、ユーザーの個人情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

## 1. 個人情報の取得と利用目的
本アプリは、ユーザーの個人情報を直接取得・収集することはありません。

本アプリは、ARFoundationのARFaceManager（ARKit/TrueDepthを基盤とする）を、フロントカメラに対するユーザーの頭部の3D位置（ARFace.transform.position）を一応のため利用しています。 顔メッシュ、ブレンドシェイプ、深度マップ、カメラ/写真フレームには一切アクセスせず、毎フレーム更新される単一のXYZ座標のみを取得しています。この設定は、ヘッドトラッキングによる視差効果（「ステレオ/ポータルビュー」）を実現するために、デバイス上で完全に利用されています。これは、ユーザーの頭部の動きに合わせて仮想カメラの位置が移動し、「水槽VR」のような効果が生じるものです。 PlayerPrefs（そのうち、ローカルデバイスストレージのみ）に保存されるのは、数値のキャリブレーションオフセット（CalibrationOffset、Vector2型）とトグル設定のみです。顔の形状データ、画像、個人を特定できる情報は一切保存されません。 このデータを使用してネットワーク通信は一切行われず、第三者やサーバーにもアップまたは共有されることはありません。
